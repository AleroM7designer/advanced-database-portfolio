# MIT 8103 Advanced Database Systems Portfolio
## Case Study: Fashion Passion E-Commerce
* **Student Name:** Alero Esther Meggison

Welcome to my repository for the MIT 8103 Advanced Database Systems course. This project implements a comprehensive database architecture for **Fashion Passion**, an online e-commerce clothing boutique.

---

### Repository Navigation & Directory Structure

Each portfolio folder contains its own dedicated documentation, implementation files, and evidence:

* **[Portfolio 1: Database Design and Modelling](./portfolio-1-database-design/README.md)**
  * *Contents:* Entity-relationship modeling, relational schema design, data dictionary, and normalization documentation for the Fashion Passion case study.
* **[Portfolio 2: Query Optimisation](./portfolio-2-query-optimisation/README.md)**
  * *Contents:* Advanced SQL queries, execution plan analysis, indexing strategies, and query performance tuning.
* **[Portfolio 3: Transactions & Concurrency](./portfolio-3-transactions-concurrency/README.md)**
  * *Contents:* Transaction management, isolation level testing, concurrency control, and deadlock mitigation.
* **[Portfolio 4: NoSQL & Document Databases](./portfolio-4-nosql/README.md)**
  * *Contents:* Document database modeling, schema design for MongoDB, and unstructured data management.
* **[Portfolio 5: Distributed and Cloud Architecture](./portfolio-5-distributed-cloud/README.md)**
  * *Contents:* MongoDB Atlas cloud cluster deployment, sharding strategy (`product_id` hashed), request routing, CAP theorem analysis, and live cloud evidence.
